# Barbearia Ramos

Site institucional com fluxo de agendamento para a Barbearia Ramos, desenvolvido com Vite, React e TypeScript.

## Tecnologias

- React
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion

## Como rodar

```bash
npm install
npm run dev
```

## Scripts

```bash
npm run build
npm run lint
npm test
```
